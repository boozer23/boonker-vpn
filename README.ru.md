# Boonker VPN

**Язык:** [English](README.md) | [Русский](README.ru.md)

Мобильный прототип VPN-приложения для iOS с интерфейсом Boonker.

## Что включено

- Интерактивный выбор VPN-сервера по стране и городу
- Вкладки «Все», «Избранное» и «Недавние»
- Поиск по стране или городу
- Выбор маршрута с лучшим пингом
- Состояние подключения, выбор протокола, метрики и настройки защиты
- Прототипы аккаунта, входа, тарифов и Premium-сценариев
- Оболочка SwiftUI/Xcode с полноэкранным веб-интерфейсом внутри iOS-приложения
- Каркас Packet Tunnel Extension и контракт backend API

## Запуск веб-прототипа

Откройте `outputs/vpn-prototype.html` в браузере или запустите любой статический веб-сервер из корня проекта.

## Сборка iOS-оболочки

Из корня проекта:

```sh
./ios/build.sh
```

Скрипт синхронизирует веб-прототип с Xcode Bundle, проверяет необходимые UI-хуки и запускает неподписанную сборку для симулятора.

## Текущий объём

Репозиторий содержит функциональный UI-прототип и каркас интеграции с iOS. Для полноценного VPN-продукта ещё нужны развёрнутый backend, настоящая конфигурация WireGuard/Packet Tunnel, безопасная авторизация, обработка покупок через StoreKit, телеметрия и подпись релизной сборки.
